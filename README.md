# 🚐 Cláudio Turismo - Sistema de Transporte Intermunicipal

Projeto desenvolvido para a disciplina de Desenvolvimento Web (UNIPÊ), consistindo num site estático responsivo para o serviço de transporte de passageiros em van na rota exclusiva **João Pessoa (PB) ⇄ Princesa Isabel (PB)**.

## 📂 Estrutura do Projeto

O repositório está organizado de forma modular em pastas específicas:

- **`html/`**: Contém todas as páginas principais da aplicação (`index.html`, `rotas.html`, `embarque.html`, `agendar.html`, `cancelar.html`).
- **`css/`**: Contém as folhas de estilo dedicadas para cada respetiva página (`style-index.css`, `style-rotas.css`, `style-embarque.css`, `style-agendar.css`, `style-cancelar.css`).
- **`imagens/`**: Concentra os recursos multimédia do projeto, incluindo os registos visuais dos pontos de embarque (Casa de Apoio e Praça da Estrela) e subpasta de vídeos demonstrativos (`video/`).

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Marcação semântica estrutural e formulários de agendamento/cancelamento.
- **CSS3**: Estilização visual personalizada e hierarquia de cores.
- **Git & GitHub**: Controlo de versão e hospedagem do código-fonte.

## 🚀 Funcionalidades

- **Início**: Apresentação institucional do serviço.
- **Rotas**: Tabela detalhada do trajeto exclusivo entre João Pessoa e Princesa Isabel.
- **Locais de Embarque**: Galeria visual com fotografias geolocalizadas e vídeo explicativo dos pontos de encontro.
- **Marcar Viagem**: Formulário interativo para solicitação de reserva de vagas.
- **Desmarcar / Contato**: Canal direto de atendimento e formulário de cancelamento de reservas.
